🤖 agentic-game-factory - Build mobile games with AI agents

Download Agentic Game Factory

Agentic-game-factory helps you create mobile games using artificial intelligence. The software handles game design, visual art, sound, and computer code. It creates a ready-to-publish mobile game while you watch the process. This tool uses the Godot 4 engine to manage technical tasks.

🚀 How it works

You provide a basic idea for your game. The software uses agents to fulfill that idea. These agents work together to write the game logic, draw the graphics, and compose music. The software includes 136 testing modules to ensure the game functions correctly. It also prepares store assets and manages in-app purchases automatically. You monitor the process at two specific checkpoints to ensure the final product matches your goals.

Follow these steps to run the software on your Windows computer.

  1. Visit the download page: Download here.
  2. Select the executable file ending in .exe for Windows.
  3. Wait for the download to finish.
  4. Find the file in your Downloads folder and double-click the icon.

  6. Follow the prompts on your screen to install the software.

📋 System requirements

To run this software, ensure your computer meets these conditions:

  • Operating System: Windows 10 or 11.
  • Memory: At least 8 gigabytes of RAM.
  • Storage: 2 gigabytes of free disk space.
  • Graphics: A card that supports OpenGL 3.3 or higher.
  • Internet: A consistent connection for downloading assets.

⚙️ Building your first game

Once you open the software, you see a central dashboard. Press the New Project button to start. Enter a description of your game idea in the text box. The software creates a plan based on your words. It will ask for your approval at two stages. First, it presents the game design. Second, it presents the assets. If you approve both, the software completes the code and prepares the game for Android.

🛠️ Troubleshooting

If the program stops during a task, ensure your internet connection works. The software relies on online databases to get game assets. If the program shows an error message, close the window and open it again. Most issues resolve after a restart. For complex errors, check the log file located in the Documents folder under AgenticGameFactory.
